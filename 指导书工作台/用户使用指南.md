# 作业指导书工作台 — 用户使用指南

> 本指南面向日常使用者，全程只需要鼠标+键盘填表，**不需要懂代码、不需要手改任何配置文件**。

---

## 一、这是干什么的

把「作业指导书」的信息填进窗口里的表格，一键生成符合公司标准版式的 Excel
（版式 = 《作业指导书版头.xlsx》，包含封面清单页 + 每工序一页详情页，格式、合并格、列宽全部自动保留）。

## 二、怎么打开

| 电脑 | 打开方式 |
|---|---|
| 家里 | 双击 `启动工作台.bat`，或双击 `发布包\作业指导书工作台.exe` |
| 公司 | 解压 `作业指导书工作台_发布包.zip`，双击里面的 `作业指导书工作台.exe`（免安装，不需要装 Python） |

⚠ 发布包注意事项：exe、`_internal` 文件夹、`作业指导书版头.xlsx` 三者必须放在同一个文件夹里，缺一不可、不能改名。

⚠ 压缩包里还带了一个子文件夹 `大模型探测\`（「免费大模型自动探测器」，跟工作台配套用的）。**它跟工作台是两码事：工作台本体不靠它也能干全部版式活；只有你要用 AI 功能（自动创建工序、AI 起草、图纸识别）才需要它。** 解压后不要把它删掉或挪走，AI 功能会去那个文件夹找 API 配置，详见下面《大模型探测（发布包里已自带）》一节。

⚠ 第一次在一台新电脑上用，如果 Windows 弹窗提示"未知应用/无法验证发布者"：先双击同目录的 `安装信任证书.bat`（按一下回车即可，不需要管理员权限），以后就不会再弹。忘了跑也没关系，弹窗里点「更多信息 → 仍要运行」同样能打开。

## 三、界面总览

顶部一排按钮：**新建 / 打开YAML / 保存 / 另存为 / 生成 Excel**（+「帮助」）。
下面三个标签页：

### 标签页 1「版头信息」——整份文档的封面信息

| 字段 | 说明 |
|---|---|
| 公司名称 / 工厂子标题 | 一般保持默认「DEMO CONTROLS / 示例温控器工厂」 |
| 文档标题 / 英文标题 | 一般保持默认「作业指导书 / Working Instruction」 |
| **文件编号 \*** | 必填。建议统一规则，如 `DEMO-RDD-W-202403-0001` |
| 版本 | 如 A、B、C，改版时升级字母 |
| **产品规格(英文) \*** | 必填，如 `demo series controller` |
| 产品规格(中文) | 如 `演示系列组件作业指导书` |
| 编制人 / 审核人 / 批准人 / 发放日期 | 审批签名信息 |
| 备注 | 如 `(★) Means key processes 表示关键工序` |

还有两张小表：
- **变更记录（版头简表）**：填封面里显示的变更历史（日期/内容/变更人）。
- **变更记录（明细表）**：填了它，生成的 Excel 会额外多一个「变更记录」页，含审核/批准列。

### 标签页 2「工序内容」——每道工序一页

左边是工序列表，按钮可「新增 / 删除 / 上移 / 下移」（顺序就是生成的页序）。
右边填当前工序的信息：

| 字段 | 说明 |
|---|---|
| **工序号 \*** | 必填，如 `DEMO-1`、`1`、`T-1`，会成为 Excel 页签名 |
| 工位名称(英文/中文) | 如 `Stamping DEMO000AA0001A` / `冲压 DEMO000AA0001A` |
| 工时(秒) | 数字；页面上显示的文字会自动按「xx秒」生成（不再带"约"字），也可在显示文本里覆盖。用「导入视频自动抽帧」载入步骤时，会按视频实际时长自动填好这个数 |
| 页码 / 视频编号 | 页码建议与工序顺序一致 |
| 附属文件编号 | 引用图纸/规范编号 |
| 编制人/审核人/批准人/日期 | 本页签名，留空则自动用版头的对应值 |

下面四个子表，用法完全一样：**添加 → 弹窗填写 → 确定**；**双击一行 = 修改**；还有删除、上移、下移。

| 子表 | 列 | 一页版式容量 |
|---|---|---|
| 作业步骤 | 步号 / 中文内容 / 英文内容 | 不限制步数（超出模板自带 4 步会自动向下扩展版面，一道工序始终排在一页里；8 步以上打印缩放会变小，会有提示） |
| 物料/辅料 | 编号 / 名称 / 规格 / 数量 / 单位 | 8 行；超出并入最后一格并提示 |
| 设备/工夹具 | 型号编号 / 名称 / 运行参数 | 6 行；同上 |
| 质检项目 | 检测项目 / 标准 / 测量方法 | 3 行；同上 |

封面清单页最多列 **29 个工序**，超出部分不进封面清单（详情页仍会生成）。

**配图版面（2026-10-22 重修）**：每一步的图片排在该步标题正下方——一步一张图时图会放到最大（横图几乎占满整块宽，竖图用足整个图片区高度）；一步多张图时同排等宽并排、放不下自动排第二排，绝不会互相压、也不会盖住步骤文字。竖拍的图片会自动按高度适配，不会被截掉。

### 标签页 3「工具箱」

| 按钮 | 干什么 |
|---|---|
| 规范化旧文件 | 选同事发来的任意旧版 Excel → **只重做版头**（第 5 行以上的标签、公司块、标题、编号、工时等），下面的正文（每一步的图片+文字、右侧设备/物料/质检表、页脚签字）**原样保留、一张图都不会丢**，步骤多于 4 步也完整保留。同时可选导出配置文件并一键载入本编辑器继续修改 |
| **一句话需求（大白话批量改）** | 选一份已有的指导书 → 用一句大白话下命令（例：`把所有的F435氩弧焊机改成F348TIG焊机，删除所有氩气充气时间`）→ 先点「先看会改哪里」看清命中几页几处 → 再点「执行」。可以同时挂几张"换配图"。**原文件不动**，另存副本到 `成品\`，改过的页面自动写变更登记。详见下面《一句话需求》一节 |
| **自动创建工序（视频 +AI）** | 选操作视频 → 程序自动抽帧 + AI 分析每步图片写操作文字 → **一键填进当前工序的步骤表**（图片 + 文字 + 工时全部自动）。适合快速创建新工序草稿，文字仍需人工核对润色 |
| **AI 模型配置** | 添加/编辑自定义大模型 API（如智谱、OpenRouter、自建模型等）。配置后 AI 起草功能将优先使用这些模型。**公司电脑离线使用必备**：配置自己的 API key 即可，无需联网探测 |
| **导入视频自动抽帧** | 选操作视频（mp4/avi/mov 等）→ 程序自动挑出画面切换瞬间的帧（挑不满则按固定间隔均匀截），存到 `素材图片\视频名\`。弹窗里可设：**起始帧**（从第几张开始）、**取帧间隔**（每几张取 1 张）、**每几张图合并为一步**（1~3 张，多图横排放同一步）；默认全部留空即用兜底值。载入时还会**按视频实际时长自动填当前工序工时**（不带"约"字，秒数取整）。之后可选择**一键把帧图填进当前工序的步骤表配图列**（覆盖原步骤），你只需逐条双击补写步骤文字 |
| **AI 起草步骤文字** | 把当前工序里**已配图的步骤**交给免费大模型看图，自动写出每步的操作文字（草稿）。先探测哪些渠道当前可用，再逐个渠道兜底重试；文字写完后仍需人工核对修改 |
| **导入图纸参数（从工程图/BOM表提取 QC Items）** | 选工程图纸/BOM表/工艺卡图片 → AI 识别图中的质量检验要求 → 弹窗列出识别结果 → 确认后写入 QC Items 表格。适合从旧图纸快速提取质检项目 |
| **导入图纸全参（物料+设备+QC 自动填入三表）** | 选工程图纸/BOM表/工艺卡图片 → AI 全面识别图中的物料编号/名称/规格、设备型号/运行参数、质检项目/标准/方法 → 弹窗列出三类结果 → 确认后自动写入物料表、设备表、QC 表三个子表（去重，不覆盖已有数据）。⚠ AI 识别工程图纸照片的精度有限，输出结果务必人工核对修正 |
| 清理素材 | 这份作业指导书**确认做完、不再需要重新生成**后，点它删除当初抽帧用的帧图目录和工作目录里的同名视频，腾出空间。只会删当前配置文件引用过的 `素材图片\视频名\` 目录，其他素材一律不碰；删之前弹窗列清单让你确认。已生成的 Excel 不受影响，但删掉后重新生成 Excel 时工序页将没有配图 |
| **清理全部测试文件** | 一键清除所有开发/测试残留（视频抽帧产生的 `.mp4` 视频、`素材图片\VID_*\` 帧图目录、`成品\` 里含「规范化版」「demo」「测试」字样的输出文件）。点之前先确认这些素材还有用就跳过此项 |
| 生成演示示例文件 | 造一份示例配置 + 示例 Excel，第一次用先看这个最直观 |
| 校验当前填写 | 检查必填项、工时数字等，绿字通过、红字报错 |
| **同步进度到云端看板** | 一键把本机 configs 里所有配置的摘要（系列/编号/版本/工序数/工时/最后修改时间）和最近生成记录上传到网页看板；浏览器打开看板网址即可随时查看进度，网页是只读的 |
| 打开输出目录 | 直接看生成的 Excel |

### 云端进度看板（可选功能）

- 网址由维护人员提供；点「同步进度到云端看板」后打开网址就能看到最新数据，不点同步网页就不会变。
- 看板现在是**一页两用**：上半部分是"三国卡牌开发进度"（另一个会话维护，工作台同步不会动它），底部是「作业指导书进度」区块，显示你最后一次同步的内容。
- 哪台电脑最后点的同步，网页就显示哪台电脑的数据（各电脑本地 configs 仍是各自的存档，网站只是展示窗）。
- 需要程序同目录有 `site_sync.json`（发布包里已带好），删除它或不点按钮就完全不联网使用，其余功能不受任何影响。
- 看板页面顶部有「下载最新发布包」按钮，点它会从 GitHub 直接下当前最新的 `wi-workbench-release.zip`（公司电脑上想重装一份、或换新电脑时用得上；这个链接是固定写法，以后出了新版不用改网页）。

### AI 起草步骤文字（可选功能，需联网）

- 用法：先「导入视频自动抽帧」载入带图步骤 → 点「AI 起草步骤文字」→ 选"只补空白"或"全部重写" → 每步旁边会自动写出一句操作描述，你逐条核对润色即可。
- 需要一份 `keys.json`（里面是你的 API key，属私密信息，**发布包里故意不带、也绝不进 zip**）。现在最省事的做法：双击同包的 `大模型探测\免费大模型自动探测器.exe` → 点「设置」填自己的 key → 它把 key 存成 `大模型探测\keys.json`，工作台的 AI 功能会自动去这个子文件夹读，不用拷来拷去。也可以自己把这个文件放在 exe 旁边：工作台先看 exe 同目录，没有才看 `大模型探测\`。
- 首次点击会花约 1 分钟探测可用渠道（之后同一开程序内不再重复探测），每步起草通常 1~10 秒；某个模型不行会自动换下一个候选。
- ⚠ 图片会上传到所选大模型渠道的服务器。涉密产品请勿使用；用哪家渠道由探测结果自动决定，与探测器工具一致。

### AI 模型配置（公司电脑离线使用必备）

- **用途**：公司电脑无法联网探测免费模型时，手动添加自己的大模型 API（如智谱、OpenRouter、自建模型等）。
- **配置方法**：
  1. 点「工具箱 → **AI 模型配置**」
  2. 点「添加模型」→ 填写：
     - **模型名称**：如"智谱 GLM-4V"
     - **API 地址**：如 `https://open.bigmodel.cn/api/paas/v4`
     - **模型名称**：如 `glm-4v`
     - **API Key**：从模型服务商获取，以 `sk-` 开头
  3. 点「保存」→ 配置文件 `ai_models.json` 自动更新
  4. **重启工作台**后生效
- **配置文件位置**：`ai_models.json`（与 exe 同目录）
- **支持格式**：OpenAI 兼容 API 格式（大部分国内大模型都支持）
- **示例配置**：
  ```json
  {
    "name": "智谱 GLM-4V",
    "base_url": "https://open.bigmodel.cn/api/paas/v4",
    "model": "glm-4v",
    "api_key": "sk-你的智谱 API Key"
  }
  ```
- **注意事项**：
  - 配置后需**重启工作台**才能生效
  - API key 是私密信息，**不要提交到 git 或分享给别人**
  - 发布包里的 `ai_models.json` 是模板，实际使用时需替换 API key

### 大模型探测（发布包里已自带，配合 AI 功能用）

- **它帮你干什么**：不用你挨个网站试。双击 `大模型探测\免费大模型自动探测器.exe`，它自己把市面上各大免费模型渠道逐个实测一遍，告诉你哪些不要钱就能用、哪些要先注册领一把 key、哪些在你当前网络下连不上。
- **和工作台的关系**：工作台的三个 AI 功能（自动创建工序、AI 起草步骤文字、图纸参数识别）都靠它找来的免费模型干活。你在这里填好 key，工作台就能直接用，**两边不用各配一遍**。
- **填一次两边通**：探测器「设置 → 填写 API key」里粘贴 key → 点该行「测试」→ 「保存并关闭」。key 存进 `大模型探测\keys.json`，工作台的 AI 起草会自动读同一个文件（先看 exe 旁边，没有才看 `大模型探测\`）。
- **它比工作台多一件事**：v1.6 起，列表下半区还列了「☁️ 免费远端平台」（GitHub Codespaces、Hugging Face Spaces 这类云端环境），但**那一区只看"网站打不打得开"，绝不自动注册、不消耗任何额度**；而且平台免费 ≠ 里面的模型免费，跑智能体仍要挂上半区找到的免费模型 key。
- **不用 AI 功能就完全不用管它**：删掉或挪走这个子文件夹，规范化、生成、一句话需求等所有版式功能照常工作，程序不会报错。
- ⚠ `keys.json` 是你的私密凭据：包里不带、不进 zip、不进 git，也别拷给别人。每台电脑各填各的。

### 步骤的「配图」列怎么用

- 每步可以放多张图片，路径之间用**分号**分隔（视频抽帧载入时会自动填好）。
- 生成 Excel 时图片自动插入各步自己的图区（A-D / E-H 列），同一步最多叠 3 张，尺寸自动缩放到图区内。
- **步骤数不限 4 步**：某道工序有 5、6、8 步时，工序页会自动往下扩出新的步骤区（每排 2 步），页脚的「批准/审核/制作 + 日期」签字栏跟着往下移，一张纸仍然只放这一道工序（整页自动缩放），不会把一道工序拆成两页。
- 版面想微调，生成后在 Excel 里拖动图片即可。

## 四、三个最常用的工作流程

### A. 新建一份作业指导书
1. 「新建」→ 填版头的带 \* 项（文件编号、产品规格）。
2. 切到「工序内容」→ 逐个新增工序、填四个子表。
3. 「工具箱 → 校验当前填写」，红字清零。
4. 「保存」→ 起个名字（自动进 `configs\产品系列名\`，同一份文件下次直接「打开YAML」改）。
5. 「生成 Excel」→ 到 `output\` 拿成品。配过图的话图片已自动排进工序页，个别位置不合适可在 Excel 里微调，然后发车间。

### B. 接手同事发来的旧 Excel
1. 「工具箱 → 规范化旧文件」→ 选旧文件。
2. 勾选导出配置、载入编辑器 → 逐项核对提取出来的内容（重点核对工序号、工时、步骤文字）。
3. 之后同流程 A 的第 3~5 步。

### C. 改版（最常见的日常维护）
1. 「打开YAML」选中该产品上次的配置。
2. 改需要变的字段/工序。
3. 版头「变更记录（版头简表）」加一行：日期 + 改了什么 + 变更人；版本号按需升级（A→B）。
4. 保存 → 生成 Excel。

### D. 用视频快速创建新工序（最常见的新增场景）
1. 在「工序内容」页**新增一个工序**，填好工序号、工位名称。
2. 点「工具箱 → **自动创建工序（视频 +AI）**」→ 选操作视频。
3. 程序自动：抽帧 → AI 分析每步图片写操作文字 → 填进步骤表（图片 + 文字 + 工时）。
4. 逐条核对/修改步骤文字（AI 生成的草稿通常 80%~90% 准确，关键动词要人工确认）。
5. 保存 → 生成 Excel。

⚠ 需要 `keys.json`（和「AI 起草步骤文字」同一份）。最省事的办法：双击同包的 `大模型探测\免费大模型自动探测器.exe`，在它的「设置」里填 key，key 就存进 `大模型探测\keys.json`，工作台自动读它，不用手动拷。

### E. 改版：用一句话批量改（改名、删项、换图）

1. 「工具箱 → 一句话需求」→「要改的文件」选一份已经做好的 xlsx（`成品\` 里的生成版、规范化版都行）。
2. 「一句话」里用大白话下命令，只认这两种句式，可以一句话里并用（逗号隔开）：
   - `把所有的〈原来的话〉改成〈新的话〉`（"改为/换成/替换为"都算）
   - `删除所有〈原来的话〉`（"删掉/去掉/移除"都算）
3. 点「先看会改哪里」→ 弹窗列出**哪几页、各改几处**。看不懂你这句话时它会直说"没拆出可执行的修改"，绝不瞎猜。
4. 要换图就点「挂一张换图…」→ 选页面 → 列表里选中第几张图 → 挑新图。可以反复挂多项；新图**沿用原图的位置和显示大小**，版面不动。
5. 点「执行（原文件不动，另存副本到 成品/）」→ 弹窗回执【实际改动】＋【变更登记】，副本名形如 `原名_改_2026-10-20.xlsx`。

**改完自动登记（厂里的规矩，程序替你写）**：

- 每个被改到的页面，都在**该页自己的「内容变更 Change the content」栏**写明改了什么 ＋ 当天日期；
- **清单页**同步登记"哪一页改了什么"（用工序号点名）；
- 清单那一栏的格子不够用时，多出来的明细自动追加在清单表格下方，小标题是「变更登记Change record（工具追加）」——这样每条都看得见，不会被行高截掉。

注意事项：

- 这句话改的是**正文**（步骤文字、设备/物料名称、配图），本来就是为了让你批量改版；和"规范化不许动正文"是两码事：规范化只换版头，一句话需求是你明确下了命令才动正文。
- 一次改不动结构：要加一步、删一步、挪工序，仍去「工序内容」页改完重新生成。
- 型号和名称常被拆在相邻两个格（「F435」一格、「氩弧焊机」一格），这种情况程序会按词对应换，回执里会写明"其中 N 格是分格替换的"。
- 改完记得打开副本逐页过一遍；确认无误后，把副本当作新的现行版本，旧副本自己决定留还是删。

## 五、家里/公司两台电脑怎么同步数据

- 所有填写内容都存在 `configs` 文件夹里（每个产品一个配置文件），成品在 `output`。
- 想把家里做的带到公司：拷 `configs` 整个文件夹覆盖公司发布包里的同名文件夹，反之亦然。
- 建议：谁改了就把 `configs` 里对应的文件发给对方，避免两边各改各的对不上。

## 六、常见问题

**Q：双击 exe 没反应 / 报错？**
先看 exe 旁边有没有生成 `启动错误.log`，有就把内容发给维护人；没有的话确认 `_internal` 和 `作业指导书版头.xlsx` 是否和 exe 放在同一文件夹。

**Q：生成的 Excel 里的图呢？**
两种方式：① 步骤表「配图」列填了图片路径（或用「导入视频自动抽帧」自动填），生成时自动插入图区；② 没配图的，生成后在 Excel 里手工插入也行。

**Q：步骤写了 7 八条会丢吗？**
不丢。超排版容量的内容会自动并入该区域最后一格，生成时日志会提示，届时可考虑拆成两个工序。

**Q：带 \* 的项不填行不行？**
不行，「校验」会红字提醒；文件编号和产品规格是每份文件的身份证。

**Q：YAML 是什么？我要学吗？**
不用学。它就是工作台「保存/打开」背后的文件格式，你只通过按钮操作它即可。
